# JavaScript Calculator 🧮

A **simple, responsive calculator** built using **HTML, CSS, and JavaScript**. This project is designed to practice JavaScript fundamentals, DOM manipulation, event handling, and interactive UI development.

### 🚀 Features

* ➕ Addition, subtraction, multiplication & division
* 🧮 Interactive calculator buttons
* 📱 Fully responsive design
* 💻 Works across desktop, tablet & mobile screens
* ⚡ Real-time calculations
* 🎨 Clean and simple UI

### 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

### 🎯 Purpose

My **first JavaScript project**, built to strengthen my JavaScript fundamentals and learn how to create responsive and interactive web applications.
